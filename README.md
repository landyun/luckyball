# LuckyBall - 双色球幸运号码预测

> 基于天干地支、阴阳五行、八字命理等传统文化，对双色球进行趣味预测。

## 功能说明

根据用户输入的彩票开奖日期和时间（含分钟），计算八字并生成推荐号码。

## 使用方式

输入格式：
```
/luckyball 2026-04-30 20:35
/luckyball 2026年4月30日20点35分
```

## 预测逻辑

1. 根据日期时间计算完整八字（含分钟精度）
2. 统计五行频率（加权）
3. 提取候选数字
4. 权重分配生成推荐号码
5. 输出前区（6个红球1-33）+后区（1个蓝球1-16）

## 刻度说明

| 分钟范围 | 刻度 | 特性 |
|---------|------|------|
| 0-19分 | 初刻 | 能量初生，静谧收敛 |
| 20-39分 | 中刻 | 能量稳定，均衡平和 |
| 40-59分 | 上刻 | 能量旺盛，活跃外放 |
